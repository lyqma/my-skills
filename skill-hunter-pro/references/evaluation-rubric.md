# 打分细则与证据标准

## 打分维度（每维 1–5 分，附证据要求）
| 维度 | 5 分标准 | 必须附带的证据 |
|------|----------|----------------|
| 供需缺口 | 主流平台几乎无在售/在售质量差且贵 | 至少 2 个渠道的搜索结果、在售商品数量与质量截图/描述 |
| 需求强度 | 搜索/提问/抱怨/复购信号强且增长 | 搜索量、话题热度、评论区原文、销量数据 |
| 痛点解决度 | 痛点真实、够痛、且无平替 | 用户原话/场景描述、替代品对比 |
| 农村适配度 | 与本地资源/手艺/气候强绑定，成本低 | 原料、产能、物流、人力成本的落地判断 |
| 可落地性 | 启动快、门槛低、资金周转可控 | 起步投入、周期、供应链可及性 |
| 竞争护城河 | 有差异化、难被快速抄袭 | 工艺/产地/资质/配方/专利/品牌等壁垒点 |

总分 = 六维加权（建议权重：供需 25%、需求 25%、痛点 20%、适配 15%、落地 10%、护城河 5%）。总分 ≥ 24/30 且无任一维 ≤ 2 分，判定为**重点机会**；否则列为观察项并注明短板。

## 三验的"证据强度"分级
- **强证据**：可核实的数据/原文/截图/链接（平台销量、搜索指数、用户原话、竞品价格与数量）。
- **中证据**：多来源交叉一致的描述、趋势性判断。
- **弱证据/存疑**：单一来源、个人推测、无第三方信号。
- 验一、验二必须有**强证据**才放行；验三允许中证据，但必须能落到"谁、何场景、多痛"的具体描述。

## 农村适配度评估清单（重点加分项）
- [ ] 本地是否天然有原料/手艺/气候/闲置劳动力优势？
- [ ] 能否形成"别处做不了或做不好"的产地差异？
- [ ] 启动与周转资金是否在本地产能可承受范围？
- [ ] 物流/包装/储存是否在当地可行？
- [ ] 能否结合本地政策、文旅、帮扶资源？
- 命中 ≥ 4 项 → 适配度判 4–5 分，可抵消部分其他维度短板。

## 报告每条必须包含
产品/机会名 · 目标人群与场景 · 痛点与价值 · 供需现状证据 · 需求证据 · 农村适配点 · 启动路径 · 风险与反证 · 综合评分与优先级。
