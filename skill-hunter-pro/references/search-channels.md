# 搜索渠道与关键词策略

## 渠道分层
- **广覆盖（第一层）**：通用网页搜索。用中英文多关键词并行搜，覆盖新闻、行业报告、论坛、博客、问答。用于发现候选与供需现状。
- **平台深挖（第二层）**：当发现具体线索或需要验证销量/评论/提问时，用浏览器直接打开以下平台阅读可见内容（帖子、评论、销量、问答）：
  - 电商：淘宝、拼多多、1688、京东、抖店 —— 看"在售多少、价格、销量、差评"（验一/验二关键）。
  - 内容/种草：小红书、抖音、快手、微博 —— 看"有没有人晒/求购/抱怨"（验三需求信号）。
  - 问答/讨论：知乎、贴吧、即刻、脉脉 —— 看真实提问与痛点原话。
  - 资讯/行业：新闻、垂直行业站、政策文件 —— 看趋势与政策机会（尤其农业、乡村振兴）。
  - 跨境（如需）：Amazon、Etsy、Shopee、速卖通 —— 看海外空白可反向引进。

## 关键词策略（决定找不找得到）
- **痛点词**：谁 + 场景 + 痛苦，如"老人 独居 吃饭难""菜农 滞销 保鲜"。
- **需求词**：求购/求助类，如"有没有XX""求推荐 XX""XX 替代品""XX 卖断了"。
- **空白探测词**：反问供给，如"XX 为什么没人做""XX 哪里买""XX 小众"。
- **平替探测词**：找现有凑合方案，如"用XX代替""平替""凑合"。
- **品类+产地**：候选品类 + 本地地名/特产名，验证农村适配与产地空白。
- **趋势词**：新概念/新生活方式 + 品类，如"极简农村""庭院经济""一人食"，提前锁定上升需求。
- 关键词要多轮换：同一候选至少用 3 组不同角度的词验证，避免"搜不到=没人做"的假象。

## 反证检索（反护腿枪必做）
针对每个候选，专门搜："XX 竞品 / XX 厂家 / XX 批发 / XX 红海 / XX 失败 / XX 不好卖"，刻意找"其实已经有人在做/在卖/在失败"的证据。

## 记录规范
每条候选至少记：产品名、来源平台与链接、发现理由、初步判断（哪一验可能成立）。后续在三验阶段补充证据与反证。
