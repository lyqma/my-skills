# 我的技能库

收集和整理豆包工作空间中的自定义技能集合。

## 目录结构

本仓库包含以下技能：

| 技能目录 | 说明 |
|---------|------|
| `skill-hunter-pro` | 全网蓝海产品猎手，用于寻找蓝海商品机会、选品验证 |
| `小云雀短剧技能` | 小云雀短剧相关技能 |
| `小云雀综合技能` | 小云雀综合类技能 |
| `小云雀营销技能` | 小云雀营销相关技能 |

## 使用说明

每个技能目录下通常包含：

- `SKILL.md`：技能说明文件（入口文档）
- `scripts/`：脚本
- `commands/`、`agents/`、`workflows/`、`examples/`、`references/`：按技能类型划分的子资源
